Video Game Sales & Ratings Dashboard
Project Overview

This project analyzes video game sales and ratings using Tableau to identify trends across genres, publishers, platforms, release years, and geographic regions.

The dataset contains 17,416 video games. I created an interactive Tableau dashboard with five visualizations to explore commercial performance and differences in consumer preferences across markets.

Critic score vs. global sales
Key Findings
Action was the highest-selling genre globally.
Nintendo was the leading publisher by global sales.
2008 had the highest total global video game sales in the dataset.
Regional preferences differed across markets, with Role-Playing games performing particularly strongly in Japan.
Critic scores had only a weak positive relationship with global sales, suggesting that strong critical reception alone was not a strong predictor of commercial success.
